# 🚀 Руководство по ускорению системы

## Проблема: CPU вместо GPU

Ваша система использует CPU-версию PyTorch, что ограничивает производительность. 

**Текущая версия:** PyTorch 2.8.0+cpu (без CUDA)

## 💡 Решение: Установка GPU версии

### 1. Проверьте вашу видеокарту:
```cmd
nvidia-smi
```

### 2. Установите правильную версию PyTorch с CUDA:

**Для RTX 4060 и других современных карт NVIDIA:**
```bash
pip uninstall torch torchvision torchaudio
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
```

**Альтернативно (CUDA 11.8):**
```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
```

### 3. Установите дополнительные ускорения:
```bash
pip install onnxruntime-gpu
pip install numba
```
