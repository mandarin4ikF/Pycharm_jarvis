# Jarvis: Объединённый план функций и улучшений
_Дата: 2025-08-13 18:15 (локально)_

Единый перечень функций для локального мультиагентного ассистента на Python (Ollama + CrewAI + LangGraph + LangChain), с приоритетом, сложностью и развернутым DoD.

Легенда приоритетов: P0 — критично сейчас, P1 — очень важно, P2 — важно/следом, R — исследование/эксперимент.

---

## 1) Ядро и оркестрация

- [ ] **Маршрутизатор сложности (Router)** — Позволяет автоматически выбирать оптимальную модель для задачи, экономя ресурсы и время ответа. (easy/medium/hard; модели: phi3 → лёгкое, mistral → среднее, llama3.1 → тяжёлое.)  
  **Приоритет:** P0, **Сложность:** 3  
  **DoD:**  
    - [ ] Эвристики для определения сложности текста реализованы  
    - [ ] Метрики качества и латентности вычисляются и логируются  
    - [ ] Пороги переключения между моделями легко настраиваются  
    - [ ] Тестовые сценарии пройдены на всех уровнях сложности  

- [ ] **Мультиагентные дебаты с голосованием** — Обеспечивает коллективное обсуждение и взвешенное решение, снижая ошибки и повышая точность ответа. (Strategist/Researcher/Critic/Synthesizer)  
  **Приоритет:** P0, **Сложность:** 6  
  **DoD:**  
    - [ ] Минимум 2 раунда аргументации реализованы  
    - [ ] Прозрачный протокол коммуникации агентов  
    - [ ] Финальное голосование с подсчетом голосов по весам  
    - [ ] Логирование всех раундов дебатов для анализа  

- [ ] **Асинхронный клиент Ollama** — это модуль, который позволяет системе одновременно общаться с несколькими LLM, с поддержкой таймаутов, ретраев и потоковой генерации.  
  **Приоритет:** P0, **Сложность:** 5  
  **DoD:**  
    - [ ] Подключение через aiohttp реализовано  
    - [ ] Поддержка потоковой генерации текста  
    - [ ] Таймауты и обработка ошибок 429 реализованы  
    - [ ] Ретраи и троттлинг для стабильности запросов  

- [ ] **Параллелизм и планировщик задач** — Позволяет одновременно запускать несколько задач и управлять очередью, обеспечивая справедливое распределение ресурсов. (LangGraph + CrewAI + asyncio)  
  **Приоритет:** P0, **Сложность:** 4  
  **DoD:**  
    - [ ] Ограничение одновременных задач задано  
    - [ ] Справедливое распределение приоритетов между задачами  
    - [ ] Логи активных и ожидающих задач ведутся  
    - [ ] Тестирование на нескольких сценариях параллельной работы  

- [ ] **Очередь задач** — Обеспечивает гарантированную доставку и повтор при сбоях, с возможностью отложенных задач. (in-memory → Redis/Celery/RQ)  
  **Приоритет:** P1, **Сложность:** 5  
  **DoD:**  
    - [ ] Гарантированная доставка задач реализована  
    - [ ] Повтор при сбоях и откат выполнен  
    - [ ] Поддержка отложенных задач  
    - [ ] Тесты на устойчивость к сбоям  

- [ ] **Autonomous Task Loop** — Позволяет системе самостоятельно ставить и выполнять задачи по циклу goal → plan → act → critique → retry, повышая автономность.  
  **Приоритет:** P0, **Сложность:** 9  
  **DoD:**  
    - [ ] Цикл автоматического выполнения задач реализован  
    - [ ] Контроль ошибок и повторное выполнение при необходимости  
    - [ ] Логирование всех шагов цикла  
    - [ ] Тестирование на нескольких типах задач  

- [ ] **Automatic Task Decomposition** — Деление задач на подзадачи с автоматическим распределением ролей, повышает масштабируемость и управляемость процессов.  
  **Приоритет:** P0, **Сложность:** 10  
  **DoD:**  
    - [ ] Алгоритм разбиения задач на подзадачи реализован  
    - [ ] Распределение подзадач между агентами  
    - [ ] Учет дедлайнов и приоритетов  
    - [ ] Тестирование на комплексных сценариях  

- [ ] **Reactive Graph (LangGraph StateGraph)** — Позволяет реагировать на события в системе, а не просто последовательно выполнять задачи, обеспечивая гибкость.  
  **Приоритет:** P1, **Сложность:** 9  
  **DoD:**  
    - [ ] Подписка на события и триггеры реализована  
    - [ ] Автоматическое создание задач по событиям  
    - [ ] Логирование реакции на события  
    - [ ] Тестирование сценариев событий  

- [ ] **Thought Tracing / Streaming Output** — Потоковое логирование рассуждений агентов для прозрачности и возможности визуализации.  
  **Приоритет:** P1, **Сложность:** 6  
  **DoD:**  
    - [ ] Потоковая передача рассуждений реализована  
    - [ ] Экспорт цепочки рассуждений в JSON  
    - [ ] Отображение для UI  
    - [ ] Тесты корректности трассировки
